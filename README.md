# AI Food Nutrition Assistant

A multimodal AI system that detects food from images and provides nutritional analysis and health advice.

## Features
- Detects food from images using computer vision
- Provides calories, carbs, fat, and protein information
- Answers health-related questions about the detected food
- Uses deep learning and image classification

## Technologies Used
- Python
- PyTorch
- TorchVision
- Computer Vision
- ImageNet pretrained models

## Project Structure
- app.py – main application
- image_analysis.py – food image detection
- text_analysis.py – question understanding
- nutrition_data.py – nutrition database
- nutrition_dataset.csv – nutrition values

## Example Output
Detected food: Pizza
